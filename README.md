# Sales Customer Segmentation Using K-Means Clustering and PCA

## Project Overview

This project performs customer segmentation using the **K-Means Clustering** algorithm on a Sales Analysis dataset. **Principal Component Analysis (PCA)** is then used for dimensionality reduction and visualization of the customer clusters.

Only the **`Sales_Data`** sheet from the Excel dataset is used for this project.

## Objectives

* Perform customer segmentation using K-Means clustering.
* Identify groups of customers with similar purchasing behavior.
* Use the Elbow Method to determine a suitable number of clusters.
* Standardize the selected numerical features.
* Apply PCA for dimensionality reduction.
* Visualize customer clusters using two principal components.
* Analyze the characteristics of each customer segment.

## Methodology

### 1. Data Selection

The `Sales_Data` sheet is loaded from the Excel workbook.

### 2. Customer Aggregation

The transaction data is grouped by `Customer_Name` to create customer-level purchasing and profitability features.

### 3. Feature Selection

Seven numerical features are selected for clustering:

* Total Sales
* Total Profit
* Total Quantity
* Average Discount
* Average Profit Margin
* Number of Orders
* Average Order Value

### 4. Standardization

The selected features are standardized using `StandardScaler`.

This is important because K-Means uses distance calculations and the features have different numerical scales.

### 5. Elbow Method

The Elbow Method is used to evaluate different values of K and identify a suitable number of customer clusters.

### 6. K-Means Clustering

The K-Means algorithm is applied to the standardized customer features.

Each customer is assigned to a cluster based on similarity in purchasing and profitability behavior.

### 7. PCA Dimensionality Reduction

Principal Component Analysis is applied to reduce the seven-dimensional feature space to two principal components:

* Principal Component 1 (PCA1)
* Principal Component 2 (PCA2)

### 8. Cluster Visualization

The two principal components are plotted using a scatter plot to visualize the customer segments.

## Visualizations

The project generates the following visualizations:

1. **Elbow Method Plot**
   Used to determine the suitable number of clusters.

2. **PCA Cluster Visualization**
   Displays the customer clusters in a two-dimensional PCA space.

3. **Cluster Size Visualization**
   Shows the number of customers belonging to each cluster.

## Results

The project identifies distinct customer groups based on their sales, profit, purchasing quantity, discounts, order frequency, and average order value.

K-Means provides the customer segmentation, while PCA makes the multidimensional clustering results easier to visualize and interpret.

## Conclusion

This project demonstrates how unsupervised machine learning can be used for customer segmentation. K-Means clustering identifies customers with similar purchasing behavior, while PCA reduces the dimensionality of the data and provides a two-dimensional representation of the identified customer segments.

The resulting customer segments can be used to support targeted marketing, customer relationship management, and sales strategy decisions.
